# Libert's Automation — GitHub Pages Demo

This is the static shareable prototype.

## Publish
1. Create a GitHub repository, for example `liberts-automation-demo`.
2. Upload `index.html`, `.nojekyll` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Choose `main` and `/(root)`.
6. Save and wait for the GitHub Pages URL.

## Demo behavior
The portal is client-side. Demo customers, quotes, tasks and other changes are stored in each visitor's browser using localStorage.

The build includes:
- CRM and lead/customer views
- Affärer / Pipeline
- Smart Offert
- create/select customer inside Smart Offert
- editable offer rows
- PDF/A4 preview
- Print / Save as PDF
- documents, calendar, tasks, automations, statistics and other prototype modules

Do not add passwords, API keys, SMTP credentials or production customer data to the repository.
